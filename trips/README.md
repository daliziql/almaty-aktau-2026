# trips 目录说明

每个行程一个独立文件夹，命名格式：`<YYYY-MM-目的地>/`，例如 `2026-10-新疆/`、`2027-02-日本大阪京都/`。

## 单个行程目录的标准结构

```
<YYYY-MM-目的地>/
├── 00-需求与约束.md     # 阶段0产出：人、时间、预算、偏好、硬约束
├── raw/               # 阶段1：原始素材（群聊摘录、文档快照），文件名带来源与日期
├── notes/             # 阶段2：分类提炼笔记、红黑榜候选
└── 行程攻略.md          # 阶段3-4：从 shared/templates/行程攻略模板.md 复制后成稿
```

## 规则

- 共用方法只引用 `../shared/`，副本只存在于行程内部的成品文件；要改工具就改 shared。
- 行程结束后在行程目录加 `99-复盘.md`，并把可复用的经验/改进回灌到 shared。
